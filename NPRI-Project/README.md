# NPRI Project
This project analyzes pollution data from Canada’s National Pollutant Release Inventory (NPRI) and uses machine learning to predict how industrial pollution will change over the next 5 years.

✅ What the Project Does

Cleans and prepares NPRI pollution data

Analyzes trends in industrial emissions

Builds models to predict future pollution growth

Identifies industries with increasing or decreasing pollution levels

🛠 Libraries Used

pandas, numpy – data cleaning & preparation

matplotlib, seaborn – visualizations

scikit-learn – machine learning models

🤖 Models Used

Linear Regression – predicts pollution trends over time

Random Forest Regressor – predicts pollution levels from multiple features

Random Forest Classifier – identifies industries likely to increase or decrease emissions

🔍 Key Insights

Pollution levels vary strongly by industry

Some industries show clear upward growth trends, others are declining

Machine learning helps estimate future emissions and highlight high-risk sectors

Feature engineering (growth rate, lagged values, totals) improves prediction accuracy

🧠 Skills Demonstrated

Data cleaning & wrangling

Feature engineering

Trend analysis

Regression & classification modeling

Model evaluation (R², RMSE, MAE)

Visualization and insight communication
