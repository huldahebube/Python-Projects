# GoAuto Predictive Pricing Model

A machine learning project designed to predict vehicle prices for GoAuto using **Python**, **feature engineering**, and **Power BI** insights.  
This project demonstrates my ability to work through the full data science lifecycle — from data cleaning, exploratory analysis, and model development to dashboard visualization and insight communication.

---

## ⭐ Project Summary

- Built a **predictive pricing model** using real vehicle listings  
- Engineered features such as **vehicle age**, **price-per-km**, and encoded categorical variables (make, model, drivetrain, fuel type)  
- Conducted **EDA** to identify key pricing drivers  
- Created an interactive **Power BI dashboard** used to validate model assumptions and present insights  
- Evaluated models using **RMSE, MAE, and R²**  
- Delivered business-facing recommendations based on model outputs and dashboard trends  

---

## 🧠 Key Insights (Business Impact)

- **Mileage, model year, and make** are the strongest predictors of price  
- New vehicles average **~56K**, while used vehicles average **~35K**  
- Luxury brands (Mercedes, Porsche, Maserati) consistently command higher prices  
- Electric and hybrid vehicles show higher-than-average pricing  
- Pricing has increased significantly from **2021–2024**, supporting age as a key feature  

These insights informed feature selection and improved model performance.

## 🧪 Technical Approach

### **Data Processing & EDA (Python)**
- pandas, numpy, matplotlib, seaborn  
- Cleaned missing values, standardized categories, removed outliers  
- Visualized price distributions, depreciation patterns, brand-level trends  

### **Machine Learning**
- **Models:** Linear Regression (baseline) → Random Forest Regressor (best performance)  
- **Evaluation:** RMSE, MAE, R²  
- **Feature Engineering:**  
  - vehicle_age  
  - price_per_km  
  - mileage buckets  
  - categorical encoding of make/model/drivetrain/fuel type  

### **Visualization (Power BI)**
- KPIs (average price, total price volume, mileage)  
- Make-level comparisons  
- New vs used price segmentation  
- Trend analysis across model years
